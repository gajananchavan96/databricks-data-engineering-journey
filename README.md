# databricks-data-engineering-journey
My 6-month journey learning Python, Pandas, PySpark and Databricks

A six-month, 26-week learning portfolio covering Python, NumPy, Pandas, PySpark, Databricks, Delta Lake, testing, orchestration and performance optimization.

## Goals
- Practice approximately 10 hours per week.
- Build weekly mini-projects with tests and documentation.
- Complete an end-to-end lakehouse capstone.

## Repository structure
- `python-foundations/`: Python exercises and utilities
- `numpy-pandas/`: local data analysis and cleaning
- `pyspark/`: distributed transformations and performance labs
- `databricks/`: notebooks and Delta Lake projects
- `capstone/`: end-to-end project, tests and architecture
- `notes/`: concise learning notes and interview preparation

## Safety
Only use synthetic, public, or otherwise authorized data. Never commit passwords, tokens, credentials, employer/client data, or proprietary code.
